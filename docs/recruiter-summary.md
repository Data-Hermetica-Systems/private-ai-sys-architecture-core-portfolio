# Recruiter Summary

## Project

Private AI Document Automation Platform

## One-line description

A sanitized public portfolio system that turns invoice-style OCR text into validated structured data and shows the extension path into Dataverse, Power Apps, Power Automate, custom connectors, review queues, and audit-ready workflow automation.

## What the repository proves now

- Node.js and JavaScript document-processing pipeline
- Synthetic OCR-style invoice input
- Invoice item segmentation
- Canonical row extraction
- Field normalization
- Required-field validation
- Quantity multiplied by unit price validation
- Net and gross weight reconciliation
- Master JSON output
- Master CSV output
- Validation flag output for human review

## What the completed architecture demonstrates

- Multi-step workflow decomposition
- Validation-first automation design
- Human-in-the-loop exception routing
- Power Platform integration planning
- Dataverse schema design
- Power Automate approval flow design
- Custom connector and OpenAPI design
- Local/private AI extension planning
- RAG over SOP, vendor, and document-family rules
- ALM and deployment readiness

## Interview positioning

This is a public sanitized demo, not a production client system. It shows how I design and implement the architecture pattern: document intake, extraction, validation, reconciliation, exception routing, and downstream workflow integration.

## Strong 30-second explanation

This portfolio demonstrates a document automation pipeline for invoice-style OCR data. It takes synthetic invoice text, segments line items, extracts canonical rows, normalizes fields, validates arithmetic and required data, reconciles weights, and produces JSON/CSV outputs plus validation flags. The extension layer maps the result into Dataverse tables, Power Apps review screens, Power Automate approvals, and a custom connector API.
